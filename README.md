# Agrosistemas — Frontend

Plataforma educativa para el fortalecimiento del pensamiento sistémico en estudiantes de sexto grado, basada en agroecología y simulación de cultivos con DSSAT.

## Información del Proyecto
- **Investigación:** Fortalecimiento de las Habilidades de Pensamiento Sistémico en Estudiantes del Grado Sexto Mediante Simuladores Educativos.
- **Estudiante Investigador:** Aurelio Pisso Villaquirán.
- **Estrategia Pedagógica:** Agroecología y Pensamiento Sistémico apoyada en DSSAT como simulador digital de cultivos.

## Módulos y Actividades
1. **Bloque 0: Introducción al Pensamiento Sistémico** (`/laboratorio/introduccion`):
   - Momento de Inicio: conceptos fundamentales, ejemplos analógicos cotidianos, proyección de video y lluvia de ideas.
2. **Bloque 2: Agroecosistemas**:
   - **Actividad 1 — Análisis del Sistema:** Simulación 6: Factores del Cultivo (`/laboratorio/factores-cultivo`).
   - **Actividad 2 — Síntesis del Sistema:** Simulación 7: Escalas Productivas (`/laboratorio/escalas-productivas`).
   - **Actividad 3 — Implementación y Estabilidad:** Simulación 8: Resiliencia Agrícola (`/laboratorio/resiliencia-agricola`).

*Nota: El Bloque 1 (Ciclo del Agua: evaporación, condensación, precipitación, infiltración y ciclo consolidado) ha sido omitido según la especificación pedagógica.*

## Ejecución en Desarrollo
```bash
npm install
ng serve
```
Navegar a `http://localhost:4200/`.
